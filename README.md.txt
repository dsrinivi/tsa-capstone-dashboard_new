# TSA Capstone Project — Time Series Analysis Dashboard

## Overview
This project performs stock forecasting and portfolio optimization using:
- ARIMA
- Holt-Winters
- Prophet

## Features
- Actual vs Predicted Forecasting
- Portfolio Allocation
- Correlation Heatmap
- Trend & Volatility Analysis
- Interactive Dashboard

## Stocks Used
- Bajaj Auto
- Titan
- Sun Pharma
- PB Fintech
- Zen Technologies

## Dashboard
Built using Streamlit.
